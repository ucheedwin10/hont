# Hont

An AI-assisted platform that helps people find and apply to scholarships and job opportunities faster.

## What it does

- **Discovers opportunities** — crawls and indexes scholarship and job listings
- **Parses resumes** — extracts structured data from uploaded resume PDFs to pre-fill applications
- **Understands application questions** — parses essay and application questions from opportunity listings
- **AI-assisted responses** — helps draft and refine application answers using a multi-provider AI setup (Claude, Gemini, OpenAI), with fallback across providers for reliability

## Stack

- **Frontend/Backend:** Next.js, TypeScript
- **Database/Auth:** Supabase
- **AI:** Anthropic Claude, Google Gemini, OpenAI (multi-provider with automatic fallback)
- **Data collection:** Firecrawl (opportunity crawling)

## Status

Built and launched independently. 50+ active users with a 76% activation rate. Originally scoped around scholarship applications, since expanded to cover job applications as well.
